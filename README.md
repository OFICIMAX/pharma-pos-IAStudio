# Pharma POS - Next.js

Esta es la versión del Punto de Venta para Farmacia construida con Next.js, React, TypeScript y Tailwind CSS.

## Requisitos Previos

- Node.js (versión 18.x o superior)
- npm o yarn

## Cómo Empezar

1. **Clona o descarga el proyecto** en tu máquina local.

2. **Abre una terminal** en la carpeta raíz del proyecto.

3. **Instala las dependencias** necesarias ejecutando:
   ```bash
   npm install
   ```
   o si usas yarn:
   ```bash
   yarn install
   ```

4. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   o si usas yarn:
   ```bash
   yarn dev
   ```

5. **Abre tu navegador** y visita [http://localhost:3000](http://localhost:3000).

La aplicación estará corriendo y lista para usar. Las credenciales de inicio de sesión por defecto son:
- **Usuario:** `admin@example.com`
- **Contraseña:** `admin123`
